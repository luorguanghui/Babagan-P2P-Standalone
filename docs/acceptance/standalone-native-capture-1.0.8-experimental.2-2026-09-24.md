# 1.0.8-experimental.2 交付记录

## 本次修改

- 自动视频总上行预算的上限从 40 Mbps 调至 50 Mbps；下拉框新增手动 50 Mbps，重启后可恢复该选择。
- 接收端在共享画面解码等待或自动切换分辨率时，用最近一帧遮住短暂空白；收到新画面后撤下遮罩。共享状态短暂为空时延迟显示“等待共享”，真正停止共享后再显示。

## 打包验证

- 客户端 73 项测试通过，目标文件 ESLint 通过。
- Windows 解包应用启动、内置采集桥、50 Mbps 选项和上一帧画布检查通过，页面无 JavaScript 错误。
- Android `versionCode=10`，v2/v3 签名验证通过；证书指纹与 1.0.7 和 1.0.8-experimental.1 相同，可覆盖升级。

## 用户实测重点

维持一次共享并开启自动画质；让网络条件促发 1080p/720p 等发送分辨率变化，观察手机端是否还会出现白闪或“等待共享”占位图。若仍出现，请记录切换前后的接收分辨率、解码/到达 fps，并提供屏幕录像，以判断是否是编码内容本身进入了占位帧。此修复的连续性行为已经通过单元测试，真实网络触发场景由用户验收。
