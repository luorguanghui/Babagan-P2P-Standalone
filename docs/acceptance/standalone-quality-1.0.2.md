# 1.0.2 画质与网络自适应

默认 1080p / 30fps，提供 720p、1080p、1440p、2160p 和 30/60fps。共享中修改设置即时作用于捕获帧率与各观看者的 RTP sender，不需要重新选窗口。保留源比例，通过统一 scaleResolutionDownBy 缩放，播放器 object-fit:contain 不裁切。

捕获保留至 3840×2160 包络内的原始像素，发送默认以选定高度为基准。网络良好时逐步提高码率，帧率稳定且带宽估计充足时将发送高度提高到基准最多 1.5 倍，以源像素上限为界。高清增强是发送更多真实像素供观看端缩小显示，不是 AI 超分、插帧或凭空提高源分辨率。

1080p30 基准码率 4 Mbps、1080p60 为 8 Mbps；其他档位按高度的 1.5 次方缩放。自适应每 3 秒统计，每连续 3 次健康采样上探最多 12%；带宽估计预留 25% 余量。丢包超过 3%、RTT 超过 350ms、带宽受限或编码时间超过单帧预算 80% 时立即回退。最大码率为基准 2.5 倍且不超过每观看者 40 Mbps。浏览器拥塞控制始终负责实际发包；设置的是码率上限，不保证填满带宽。

逐观看者独立控制；多人 mesh 总上行是各连接发送速率之和。缺少带宽或接收反馈不会启用高清分辨率增强。静态屏幕不足目标帧率时不据此触发升档，也不把缺失帧率标成已达标。没有额外向 Worker 发送测速流量。

主页实时统计展示总上/下行、每成员媒体吞吐、实际发送/接收分辨率和帧率、码率上限、带宽估计和调整原因。速率由 RTP 字节差值计算（不含全部网络协议开销），帧率由编码/解码帧数差值计算。未连接时显示未测量。

验证：策略测试覆盖上探、拥塞/CPU 退让、未知数据、静态画面与 4:3/超宽/竖屏缩放。真实 Cloudflare TURN 双端测试使用合成 640×480 屏幕，验证 4:3、设置热切换、统计显示、停止/重连/结束。该合成源仅 10fps，不构成真实 1080p60 性能验收。Android 包签名验证通过；没有 Android 真机测试。

1.0.3 验证补充：16 项单测与 ESLint 通过；真实 TURN 双端验证捕获约束没有 width/height/aspectRatio，640×480 原始源在观看端仍为 640×480；共享中 60→30fps、原始→720p 和关闭自适应通过。打包后的内部 EXE 通过预览选择器和线上入会/结束测试。Android 1.0.3 versionCode=4，使用同一发布密钥，APK v2/v3 校验通过。
